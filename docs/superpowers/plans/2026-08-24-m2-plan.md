# M2 分类交付 · 实施计划

依据:PRD §7 M2 + M1 评审收敛文档的已知边界/推迟项(docs/superpowers/reviews/2026-08-24-m1-review-convergence.md)。

## 范围

**主线功能**(PRD):缩略图索引、分类工作台(键盘流)、回收站(两段式删除)、交付打包+清单(工况 B 按拍摄时间半天分包、不压缩)。

**M1 遗留技术债**(评审既定,随 M2 落):卷 UUID/序列号强身份、平台原子改名(RENAME_EXCL/link)、回读校验绕页缓存(F_NOCACHE/O_DIRECT)、多机 journal 读回 + 5–10s 轮询对账(跨机任务可见性)、EXIF DateTimeOriginal 优先于 mtime、项目创建事务性(staging+原子改名)、进度事件 delta 专用 DTO、任务句柄回收(L20)、卡死 copying 状态的清理入口(L21)、symlink/空目录语义明示(L22)、文件明细虚拟滚动。
