## 纪律条款(显式入计划,不靠自觉——M2 教训)

- **路径/链接闸适用清单**(每处都是任务验收项):转码输出目录(`4. 转码素材`
  落地闸+相机夹名词法闸)、归档外部目录(`validate_dest_layout`+链接检查+空间预检)、
  工况 A 素材命名空间闸(新增 `resolve_asset_a`:首段 ∈ SCENARIO_A_DIRS)、
  `thumb://` 协议(缓存名 `^[0-9a-f]{16}\.jpg$` 白名单+thumbs 目录闸+拒链接)、
  分析缓存目录、成片扫描目录、模型/sidecar 资源路径。
- **sidecar 纪律**:shell 权限一律不进 webview(capabilities 不加 shell),
  ffmpeg 只在 Rust 侧 spawn;参数数组传递绝不拼 shell 串;`-nostdin -hide_banner -n`
  (永不 `-y`);源路径 `-protocol_whitelist file`;stderr 必须并发消费(防管道死锁)。
- **零静默清单**(每个降级点点名 notice code):sidecar 缺失/损坏
  `ffmpeg-missing`、硬编探测失败回软编 `hwenc-fallback`、真实素材硬编运行时失败软编重试 `hwenc-runtime-fallback`、模型校验失败=**硬失败禁用 AI**
  `ai-models-corrupt`、高负载判定跳过件列表 `transcode-skipped`、分析缓存写失败
  `analysis-cache-degraded`、thumb 协议连续失败聚合 `thumb-protocol-degraded`、
  作业取消清理结果 `job-cancelled`、空间预检不足 `disk-space-insufficient`。
- **脚本替换纪律**:跨面契约替换(T0.3 为最)每波给出旧/新符号 `rg` 计数对照;
  代码手术用带匹配校验的编辑;提交前逐处 grep 验证宣称。
- **测试随任务落地**(不留到收口);关键测试变异验证;CI 冒烟必须用**将被打包的**
  sidecar 与模型(解包 installer 校验存在性+SHA-256),系统 ffmpeg 不算数。

## 决策门(D 波,开工第一批,产出裁决记录文档)

- **D1 制品矩阵**:三平台 ffmpeg/ffprobe 静态构建来源(GPL 声明入 repo,public!)、
  SHA-256 入库、`externalBin` target-triple 命名、macOS 随 app 签名公证**当场验一次
  release 构建**;ONNX Runtime(ort,**M3 只做 CPU EP**,GPU EP 顺延——
  CoreML/DirectML 是不同 ORT 二进制矩阵,不是 feature 开关)三平台打包 spike;
  模型:YuNet(**MIT**,opencv_zoo face_detection_yunet;D1 固定具体模型文件、
  版本/提交与 SHA-256,人脸框供清晰度区域加权)+ 聚类**纯算法基线**
  (时间邻近+降采样 dHash/直方图相关,不上 embedding 模型,实测不够再议);
  **闭眼:找不到许可证干净且真实样本验过的开闭眼模型即砍**,写进 PRD 能力边界
  (YuNet 5 点每眼仅 1 点,EAR 不可实现——v1 的降级方案作废)。
  全部模型:LICENSE+来源 URL+SHA-256 入库,CI 校验,启动校验失败=禁用 AI+可见 error。
- **D2 Job 协议**:状态机合法转移**仅限** `queued→running|cancelled`、
  `running→done|failed|cancelled`,终态不可逆;取消与完成竞争:先到先得,
  worker 在终态发布点做一次 CAS 式检查,竞输方放弃发布;快照+revision 单调序号
  (沿 copy://progress 模式)、取消令牌+子进程强杀(Windows 进程树)、
  panic 收尾(catch_unwind+终态必发)、typed result。
  **互斥 guard 只由 running worker 持有**:`queued→running` 时获取、
  终态发布前释放,绝不进入历史 Job 记录。
  **作业不持久化**,幂等由输出语义承担:转码「输出已存在=already-transcoded skip
  (独立机器码)」+显式「强制重转」(二次确认,唯一覆盖入口,先删后转);
  交付沿既有 verified-skip。auto_proxy:manifest 持久化**完整意图+稳定 intent ID**;
  启动时对未完成意图做 **at-least-once 补投递**(以 intent ID 去重,
  转码输出 skip 语义天然容忍重复);**仅整批完成后**才记 completed
  (不宣称 exactly-once)。应用退出前确认活跃作业(提示等待/取消);
  强退路径 kill/reap 子进程;staging 名带 machineId+jobId,
  启动清理只清本机+可见提示。
- **D3 互斥矩阵**(落代码注释+单测):OpsMutex 改 **Arc+owned guard**(M2 三组单测
  同批迁移);delivery↔sorting 语义不变;**transcode 独立 guard**(工况 A,
  与 B 的 sorting/delivery 天然不相交,仅同 kind 排队+同项目互斥);
  **analyze 不进互斥**(只读,文件消失沿索引线程 missing 语义);
  `install_update` 闸并入:tasks.any_running **或 JobManager 有活跃作业**即拒。
- **D4 分析存储**:`.ocard/analysis/features-<machineId>.jsonl` **每机一份纯追加**
  (与 §6.3 журнал同构,零跨机写竞争);只存 per-file 特征(dHash/直方图/清晰度/
  曝光/faces),**不存 groupId**(查询时确定性现算+稳定 tie-break);记录字段含:源指纹
  (rel+size+mtime 的 xxh3)、schema 版本、模型 SHA-256、预处理/评分算法版本;
  **读端只采信与当前版本全匹配的记录**(不匹配=视为未分析,重算);
  跨机同键冲突的全局确定性选择:取 analyzedAt 最新者,持平取 machineId 字典序大者。
  读端合并全部 `features-*.jsonl`,坏行计数上报。
- **D5 M2 前置批范围裁决**:跨机分类事件重放/状态折叠→**顺延出 M3**(依赖日志镜像
  设计,M2 声明的「先 rename 者胜+横幅」为长期语义,记入收敛文档);
  T0.4 索引压缩→**撤销不做**(M2 已声明行级体量可接受;若实际膨胀再按
  「每机一份索引」方案设计);file_type Err 注入→维持「不可注入」声明。
  PRD 未清账项:「待修→已修」流转提示、交付「已上传」手动勾选→**并入 M3**(T3);
  RAW libraw 全解码→**显式顺延**(内嵌预览为长期声明边界,收口报告向用户明示)。

### W6 T1.3/T1.4/T1.5 转码作业
- 代理:ffprobe 解析(色彩传递 arib-std-b67/smpte2084、位深、码率、codec)→
  「高负载素材判定」(规则 UI 可见、逐文件理由、**跳过件成列表**、整夹强制全转+
  逐文件覆盖);输出 1080p H.264 至 `4. 转码素材/<相机夹>/`(全套路径闸);
  staging `.{machineId}.{jobId}.transpart`;
  **硬编运行时失败**(初始化/不支持类错误)对同文件**至多一次软编重试**+可见告警;
  落位前**输出 ffprobe 全量验证**:codec、尺寸、pix_fmt、音频流存在性、
  色彩标签、时长±1s,全部符合目标 profile 才 rename;
  进度解析 `-progress pipe:1`(out_time_us 优先、无 duration 退化不确定态、
  progress=end 判终、stderr 并发消费);空间预检。
- 归档:三档按 backend 定质量映射(软编 CRF18/23/28;硬编按各自质量参数,
  逐 backend 写映射表+输出不变量),输出目录 validate_dest_layout。
- auto_proxy:manifest 持久化+补投递(D2);审计 transcode_started/completed/cancelled
  入 journal(outbox 兜底沿用),RemoteActivityBanner 显示他机转码。
- 视频首帧图(M2 记账):转码路径顺带 `-vf thumbnail` 抽帧进缩略图缓存。

### W7 T2 AI 客观分析(CPU,纯算法优先)
- 分析作业(不进互斥):**单次解码流水线**(rayon 并行,worker 数=物理核-1;
  每 item catch_unwind 隔离)——解码一次产出:320 缩略图(复用 M2 缓存)、
  中心/人脸区**高分辨率裁块**(清晰度在裁块上算,不在 320px 上算)、
  降采样 dHash+直方图。**不塞回 IndexManager**,索引线程保持既有职责。
- YuNet 人脸框(ONNX/ort CPU);闭眼按 D1 裁决执行或砍。
- 聚类:时间邻近(≤3s)+dHash/直方图相关,查询时现算,组内综合分排序首位
  「建议保留」;**同组连续且不跨分页**(后端排序保证);「按建议筛选」做成
  list_pending_assets 后端参数(mock/测试同步)。
- UI:折叠组**恰占一格**(角标 ×N,展开走 overlay)保住 VirtualGrid 等高行与
  M2 选择模型;角标(糊/过曝/闭眼[若保留]);AI 只标注不动文件。
- 特征缓存按 D4;EXIF orientation 处理;评分固定分辨率归一。
- 性能验收:**SLA 只用真实素材**——需用户提供(或授权使用既有项目的)
  1000 张 24MP 量级真实相机 JPEG(含 ≥100 张连拍),固定参考机、
  记录 CPU/RAM/存储(本地 vs NAS)/线程数、release build、冷缓存步骤,
  实测 ≤5min 出报告;素材就位前用全尺寸高保真合成集做工程预验
  (不作为 SLA 证据);CI 用小集做**非回退**性能回归(阈值宽松防抖动)。
  **依赖用户输入:真实素材集,收口前需向用户征集。**

### W8 T3 成片命名校验 + 清账小项
- 命名 grammar 无歧义化(下划线片名规则、分辨率/用途/版本 token 表)先行文档化;
  页面**可见期 5-10s 轮询**(SMB 无可靠 watch);文件名解析基线+**ffprobe 交叉核对
  真实分辨率**(名 4K 实 1080 标红);不可读项零静默上报。
- 「待修→已修」流转提示(检测已修出现同名成品→提示删待修原稿,人工确认);
  交付「已上传」手动勾选(状态存 .ocard,跨机可见)。
