## 收敛结果(全部修复)

**codex 独家 P0**:侧栏切项目不再卸载页面后,回收站屏保留 A 项目旧清单,
「清空」确认框显示 A 的数量却对 B 执行——不可逆误删。修:切项目清账+
收确认框+加载中禁清空;同类隐患(拷卡确认屏跨项目、分类工作台旧路径
配新项目)一并隔离,各有回归测试。

两路撞车:指纹唯一性缺失(克隆/重复登记稳定认错卡)、Select ARIA
焦点模型不成立(缺 aria-activedescendant)。

opus 独家 P1:Select scroll 收起时 focus() 把视口拽回触发器(恰是要根治
的跳变症状)→ 收起不回焦 + preventScroll;绑定容量取前端缓存(拔 A 插 B
同挂载点写错卡)→ 后端实测容量 + 卷名核对;安全链路零测试 → 绑定双闸
集成测试 + match_card 纯函数化四连测。

codex 独家 P1:未登记指纹时卷标兜底可落在绑着别的指纹的卡上 →
兜底仅限从未绑定过的旧卡,冲突可见。

P2 择要:系统盘双向排除指纹(探测+拷卡写入,与登记闸对称);Esc 不冒泡
连关外层 dialog;checkbox 字号继承;「N 张」→「N 次」(manifest 计次,
同卡重拷会计多);scrollbar 属性挪 :root;stacking.test 补 select-pop 层级。

## 声明边界(不修,记录口径)

- 绑定/拷卡的挂载点 TOCTOU 微窗口:最坏后果为已卸载空壳目录留 36 字节
  指纹文件,与既有 start_copy 同强度。
- 非系统内部数据盘可被显式选择绑定:这是功能本身(绑"卡状"卷),
  由用户显式动作触发。
- read_volume_uid 不区分「文件不存在」与「读取失败」;损坏指纹因
  create_new 不可自愈。
- VirtualGrid 同值重复定位请求不再滚动(需 {index,seq} 语义时再引入)。
- copy_incomplete 无跨版本兜底:Tauri 整包发布,不存在半升级组合。
- Select 不响应 ResizeObserver 级布局变化(scroll/resize 已覆盖);
  会话门(z80)内禁放 Select(pop z70),由 stacking.test 钉住口径。
